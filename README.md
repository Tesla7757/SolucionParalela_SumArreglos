# Suma de arreglos con OpenMP

Programa en C++ que compara la ejecución secuencial y paralela
usando OpenMP para sumar dos arreglos de tamaño grande.

## Tecnologías
- C++
- OpenMP
- Visual Studio

## Descripción
El programa ejecuta la suma de dos arreglos primero de forma secuencial
y luego de forma paralela utilizando 2 hilos, comparando los tiempos
de ejecución.

## Ejecución
Proyecto compilado y ejecutado en Visual Studio.
